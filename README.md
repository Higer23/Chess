# Modern Chess AI

A browser-based chess game with an AI opponent, implemented as a single HTML page.

## Features

- Play chess against the computer in the browser
- Runs without a server or build step

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Higer23/Chess.git
   cd Chess
   ```
2. Open `index.html` in a modern browser and start playing.
